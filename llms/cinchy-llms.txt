# Cinchy

> Cinchy is a data collaboration / dataware platform whose network-based data architecture lets applications share live, governed data without copies or point-to-point integration. Its current focus, PeriMind, is an enterprise control plane for AI that secures, governs, and audits interactions between AI agents and enterprise systems and data. The platform exposes a REST API for executing Cinchy Query Language (CQL), running saved queries, triggering data-sync jobs, and managing secrets.
